Basics of Node.js

Node.js

📘 Beginner-friendly explanation

Node.js is a JavaScript runtime built on the V8 engine. It allows JavaScript to run outside the browser, including on servers. Its event-driven model makes it effective for I/O-heavy applications.

  • JavaScript runtime outside the browser
  • Uses the V8 JavaScript engine
  • Supports event-driven, non-blocking programming
  • Includes built-in modules such as http, fs, events, os and stream

Events & Listeners

Node.js

📘 Beginner-friendly explanation

Node.js follows an event-driven model. An EventEmitter can announce that something happened, and listeners register callback functions that run when the event occurs.

  • EventEmitter creates custom event sources
  • .on() registers a listener
  • .emit() fires an event
  • Listeners receive values passed by emit

Timers & Callbacks

Node.js

📘 Beginner-friendly explanation

Timers schedule work for later. Callbacks are functions supplied to another operation so they can run after that operation completes. Node.js provides setTimeout, setInterval and setImmediate.

  • setTimeout runs once after a delay
  • setInterval repeats until cleared
  • setImmediate schedules work for a later event-loop phase
  • Callbacks are central to asynchronous programming

Implementing HTTP Services

Node.js

📘 Beginner-friendly explanation

The built-in http module can create a web server. A request object describes the incoming request, while the response object is used to set headers, status codes and response content.

  • http.createServer creates a server
  • req.url supports simple routing
  • req.method identifies GET, POST and other methods
  • res.writeHead sets status/headers
  • res.end completes the response

Go

📘 Beginner-friendly explanation

Maps store key-value pairs. They are useful when values should be retrieved by meaningful keys. Go's comma-ok idiom is used to check whether a key exists.

  • map[K]V declares key/value types
  • Assignment inserts or updates
  • delete removes a key
  • value, ok := m[key] checks presence
